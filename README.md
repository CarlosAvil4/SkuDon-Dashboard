# Dashboard-Company SkuDon

### Dashboard Link : https://app.powerbi.com/groups/me/reports/db50d4eb-3961-4d1f-be4c-c3d9fd622037/ReportSection

## Problem Statement

This dashboard provides an in-depth analysis of Sku-Don's workforce across different states in the United States. Key metrics include total employees, gender distribution, average age, average salary, and employee performance evaluation. The dashboard features visualizations such as a US map with employee distribution, salary brackets, age groups, and performance ratings. Additionally, detailed insights on department-wise salary analysis and performance evaluation are available across multiple pages. This tool helps decision-makers understand workforce trends and make data-driven decisions.


### Steps Followed for Creating SkuDon's Dashboard

- Step 1 : Load data into PowerBI Desktop, dataset is a csv file.

- Step 2: Power Query Editor: Enabled "Column distribution," "Column quality," and "Column profile" options.

- Step 3: Data Validation; Checked for null values and errors, finding no significant issues.

- Step 4: Added a US map with circles representing employee count per state.

- Step 5: Key Metrics added card visuals displaying:

  (a) Total employees

  (b) Percentage of male and female employees

  (c) Average employee age

  (d) Average salary

  (e) Average employee evaluation score

- Step 6: Salary Distribution. Displayed the number of employees earning within the following salary brackets:

    $0 - $40K

    $40K - $60K

    $60K - $80K

    $80K - $100K

    Over $100K

- Step 7: Age Grouping, Classified employees into age groups:

    20-30 years

    30-40 years

    40-50 years

    50-60 years

    60-70 years

- Step 8: Performance Evaluation, Grouped employees based on performance ratings:

    0-6

    6-7

    7-8

    8-9

    9-10

- Step 9: Included a table displaying employee names and details.

- Additional Pages:

    Detailed salary analysis

    Performance evaluation insights

- Department-wise Filtering: Added filters for:

    Production

    Technology

    Administration

    Sales

    Software Engineers

    Executives

- Step 10: The dashboard was published on Power BI Service.

This dashboard enables Sku-Don to visualize workforce distribution across states, analyze salary trends, and assess employee performance for informed decision-making.
